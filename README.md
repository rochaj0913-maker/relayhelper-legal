## Setup

1. Create a new GitHub repo named `relayhelper-legal` under the `rochaj0913-maker` account
2. Push all files in this folder to the `main` branch
3. In repo Settings → Pages → Source: `main` branch / `/ (root)`
4. Pages will be live at the URLs above within a few minutes
